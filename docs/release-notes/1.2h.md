- **Elvis, redone:** the white Aloha '73 eagle suit: a pearl shell with gold piping, red, blue and gold stones, on a night-blue stage.
- **New theme, Elvis '68:** the Comeback Special: black leather, stitching and red marquee bulbs. 25 themes in all.
- **The whole file name in the title:** a track without a title tag now scrolls its full file name (up to 127 bytes), not a name cut at 36 characters.
- **Room for portrait mode:** queue names are kept to 32 characters internally, which frees 4 KB of code space for the coming portrait mode. Nothing visible changes.
- **Audio guard:** every build now proves that the audio, Bluetooth, player and decoder code is identical to the last release. In this version it is, byte for byte.
