- **Install at start-up:** copy `HIFIEC70.IMG` to the player's top folder and restart. FROST checks it, installs it after a 3-second countdown (BACK: not now), deletes the file and restarts. Already installed: the file is just deleted. Not valid, or a low battery without the cable: a message, and the file stays. Install a firmware in the main menu still works for any `.IMG` name.
- **Safe deletion:** the file is removed in an order that stays safe if the power goes, and it's tested on real FAT32 disks at every build.
- **Room for portrait mode:** the installer, the USB disk and the charging screen are now loaded only when used, which frees 9 KB for the coming portrait mode.
- **Audio guard:** the audio, Bluetooth, player and decoder code is identical to 1.2h.

Coming from 1.2h or older: install this one from the menu (Install a firmware); from 1.2i on, copy and restart.
