# Notes for Claude

## Repository scope

This repository is only for FROST, the custom firmware for the SNOWSKY Echo Mini.

- Every new, unrelated project gets its own new GitHub repository. Never add unrelated
  projects, experiments or apps to this repository, not even on a side branch.
- If the session has no repository for the new project yet, stop and ask the user to
  create one (and to give the Claude GitHub App access to it) before writing or pushing
  anything.
